## Automatic contribution updates

The profile uses a committed snapshot of merged contributions from selected GitHub, KDE Invent, and Chromium Gerrit projects. Edit [`config/contributions.json`](config/contributions.json) through a PR to add projects, filter changes, exclude reverted work, or customize summaries. A fortnightly GitHub Action proposes evidence-based Gemini summaries for new contributions through one review PR. Historical descriptions and dates are frozen.

See [configuration and sync instructions](config/README.md) for source examples, summary extraction, scheduling, and permissions. Run `npm run sync:contributions` to refresh locally and `npm run test:contributions` to check the sync.
